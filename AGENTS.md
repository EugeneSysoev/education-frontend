# Контекст для Codex

Этот репозиторий — единая учебная система подготовки к Frontend-разработке. Перед любой учебной работой откройте [хронологию](docs/learning/README.md), затем прочитайте файл активного дня и связанные с ним исходники.

Локальная папка: `C:\Users\User\Desktop\education-frontend`. Официальный GitHub-репозиторий: [EugeneSysoev/education-frontend](https://github.com/EugeneSysoev/education-frontend). Используйте его как `origin` для обязательного push при завершении дня.

## Текущий контекст

- День 1, 14 сентября 2026: диагностика JavaScript. Все 8 тестов проходят после разбора с подсказками. Основные зоны роста: методы массивов, замыкания, ссылочная идентичность, `Promise` и объяснение решений своими словами.
- День 2, 15 сентября 2026: React state and effects. Реализованы Accordion с поднятым состоянием и Timer с `useEffect`, cleanup и функциональным обновлением состояния.
- День 3, 16–17 сентября 2026: первая версия Holidays App завершена. Реализованы запросы к OpenHolidays API, выбор страны, TanStack Query и состояния loading/error/empty/success. Runtime-проверка внешнего JSON перенесена в следующий учебный день.
- День 4, 18 сентября 2026: следующий учебный день. Первый шаг — принять ответы API как `unknown` и написать type guards для минимальных моделей страны и праздника; затем проверить ошибочный JSON и закрепить поток server state.

Подробности и ссылки на доказательства хранятся только в `docs/learning/README.md` и файлах отдельных дней. Обновляйте историю там, а в этом файле оставляйте лишь краткий маршрут и актуальный статус.

В Codex служебная папка `.git` этого checkout может быть доступна только для чтения. В таком случае сверяйтесь с `origin/main` через свежий clone, создавайте обычный последующий commit от актуального remote HEAD и никогда не используйте force push.

## Учебный контракт

- Ученик сначала делает самостоятельную попытку. Начинайте с направляющего вопроса, затем давайте минимальную подсказку; готовое решение показывайте только после попытки и разбора.
- Проверяйте корректность, TypeScript, читаемость, архитектуру и способность ученика объяснить поток данных и компромиссы.
- Объяснения и журналы ведите на русском. Имена файлов, компонентов, переменных, типов и сообщения коммитов пишите на английском.
- Темп определяется освоением темы, а не календарём. Базовая тема освоена, когда ученик решает типовую задачу, объясняет решение и воспроизводит ключевую часть без копирования.

## Обязательное завершение учебного дня

День можно пометить завершённым только когда выполнены все пункты:

1. В файле дня заполнены фактический результат, затраченное время, ошибки, полученная помощь и тема для повторения.
2. Обновлены `docs/learning/README.md` и `learning-log/skills-matrix.md` на основании наблюдаемого результата.
3. Запущены относящиеся к работе тесты, TypeScript-сборка и линтер; результат записан в файл дня.
4. Все изменения собраны в осмысленный Git-коммит и отправлены в настроенный remote.
5. Создан и связан из хронологии план следующего учебного дня с первым конкретным шагом.

Если commit или push невозможен, зафиксируйте точную причину в файле дня и не отмечайте день завершённым.
