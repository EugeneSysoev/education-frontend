# Закрепление пробелов JavaScript — блок 1

Цель блока — повторно решить знакомые классы задач в новом контексте и проверить, что решение получается без копирования кода из диагностики.

## Правила работы

1. Выполняйте задачи по порядку и не открывайте старые решения до первой законченной попытки.
2. Перед кодом запишите краткий план: какие данные входят, что должно выйти и какие операции нужны.
3. Запускайте только тест текущей задачи, пока она не готова.
4. Если застряли, пришлите код, гипотезу и конкретный вопрос. Сначала будет направляющий вопрос, затем минимальная подсказка.
5. После зелёных тестов объясните решение своими словами и заполните рефлексию в [`answers.md`](answers.md).

## Задание 0 — event loop, 10 минут

Не запускайте код до письменного ответа в `answers.md`.

```js
console.log("start");

setTimeout(() => console.log("timer"), 0);

Promise.resolve()
  .then(() => {
    console.log("promise-1");
    queueMicrotask(() => console.log("microtask-inside"));
  })
  .then(() => console.log("promise-2"));

queueMicrotask(() => console.log("microtask-outside"));

console.log("end");
```

Запишите точный порядок строк и отдельно объясните:
start
end
promise-1
microtask-inside
promise-2
microtask-outside
timer

Я посмотрел ответ и вижу, что записал неверно объясни ошибки и почему так работает очередь в микротаске.

- что выполняется синхронно; start и end выполняется синхронно
- в каком порядке попадают в очередь первая `.then(...)` и внешний `queueMicrotask`;
- когда в очередь добавляются `microtask-inside` и второй `.then(...)`;
- почему таймер выполняется последним. Потому что это макротаск и он не является приоритетной очередью
