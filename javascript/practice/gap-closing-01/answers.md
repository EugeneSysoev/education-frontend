## Задание 0 — event loop

Предполагаемый порядок вывода:

Первоначальный ответ:

```text
start
end
promise-1
microtask-inside
promise-2
microtask-outside
timer
```

После разбора:

```text
start
end
promise-1
microtask-outside
microtask-inside
promise-2
timer
```

Объяснение:

`start` и `end` выполняются синхронно. Первый обработчик `.then(...)`
попадает в очередь микрозадач раньше внешнего `queueMicrotask`. Когда первый
`.then(...)` выполняется, внешний `queueMicrotask` уже находится в очереди.
Только после него в конец очереди добавляются `microtask-inside` и обработчик
следующего `.then(...)`. Таймер относится к следующей task и выполняется после
опустошения очереди микрозадач.

Ошибка первоначального ответа: новые микрозадачи были мысленно поставлены перед
уже ожидающей `microtask-outside`, хотя очередь обрабатывается в порядке FIFO.

- Фактическое время: не фиксировалось; задним числом не восстановлено.
- Что получилось самостоятельно: по файлам нельзя достоверно отделить

- Где потребовалась помощь: по файлам подтверждён запрос на разбор очереди
  микрозадач; объём помощи по четырём реализациям не зафиксирован.
- Какую ошибку важно не повторить: микрозадача, добавленная во время выполнения
  другой микрозадачи, не обгоняет уже находящиеся в очереди микрозадачи.
- Что могу объяснить без кода: пока не проверено устным разбором. По коду нужно
  отдельно объяснить цепочку `filter` → `map` → `toSorted`, structural sharing,
  защитные копии состояния замыкания и параллельный запуск перед
  `Promise.allSettled`.
