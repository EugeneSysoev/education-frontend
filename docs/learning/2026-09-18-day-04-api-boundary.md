# День 4 — API boundary and type guards

Дата: 18 сентября 2026
Статус: запланирован

## Цель

Закрепить границу между недоверенными данными сервера и типизированным приложением. После занятия функции data layer должны возвращать `Country[]` и `PublicHoliday[]` только после runtime-проверки ответа.

## Первый шаг

Открыть `react-lab/src/exercises/holidays-app/api.ts`. Для одного ответа API:

1. Сохранить результат `response.json()` в переменную типа `unknown`.
2. Своими словами перечислить проверки, необходимые для `LocalizedText` и `Country`.
3. Написать первый type guard без `any` и type assertions `as`.

Критерий: ученик может объяснить, почему TypeScript-тип функции не доказывает форму JSON, пришедшего по сети.

## Практика

1. Проверить `LocalizedText`, `Country` и массив стран.
2. Проверить `PublicHoliday` и массив праздников.
3. Выбросить понятную ошибку при неожиданной форме ответа.
4. Проверить корректный и намеренно испорченный JSON.
5. Повторить поток: local state → `queryKey` → `queryFn` → validation → cache → render.

## Критерии завершения

- В data layer нет `any` и непроверенных type assertions.
- Корректный ответ API отображается как раньше.
- Некорректный JSON переводит query в error state.
- `npm test`, `npm run build:sandbox` и `npm run lint` проходят.
- Заполнены журнал, матрица навыков и следующий план; изменения закоммичены и отправлены в GitHub.
