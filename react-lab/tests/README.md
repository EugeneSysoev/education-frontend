# Hacker News checks

Проверки подготовлены Codex при закрытии занятия 1–2 октября; они не являются
самостоятельной работой ученика. Используют реальные функции api.ts и компонент
HackerNewsApp без изменения приложения.

Из каталога react-lab, на Node.js 24 (проверено на 24.21.0):

```bash
node --test --test-isolation=none tests/hacker-news-api.test.mjs
```

Девять контрактных тестов: зависимость этапов, первые десять id, параллельность,
полный результат и порядок, empty, HTTP-ошибки списка и одного item, неверная форма,
null item, optional URL, обязательные поля и повреждённый JSON. Fetch подменяется
только внутри тестов и восстанавливается node:test.

## Браузерная проверка

```bash
npm exec vite -- --config tests/ui/vite.config.ts --configLoader native --host 127.0.0.1 --port 5174 --strictPort
```

Откройте http://127.0.0.1:5174/?scenario=retry. Первый запрос возвращает HTTP 503:
должны появиться ошибка и кнопка «Повторить». Нажмите её: появляются загрузка,
затем десять карточек; число запросов списка меняется с 1 на 2. Одна деталь
задерживается на 2,5 секунды — до её завершения частичный список отсутствует.

Другие сценарии задаются параметром scenario:

- empty: «Публикаций пока нет», без списка и кнопки ошибки.
- item-error: HTTP 500 одной детали; общая ошибка, без девяти остальных карточек.
- invalid: объект вместо массива id; ошибка формы ответа.
- unmount: нажмите «Размонтировать», пока идёт загрузка; последняя деталь задержана
  на 15 секунд. После её завершения компонент остаётся размонтированным.

Публикация 2 не содержит URL и показывает «Внешней ссылки нет». Тестовая страница
имеет отдельную точку входа и подменяет fetch только в своём документе. Обычная
страница приложения продолжает обращаться к настоящему Hacker News API.

Размонтирование снимает подписку React на query; транспортная отмена fetch не
реализована, поскольку функции API не принимают AbortSignal.
