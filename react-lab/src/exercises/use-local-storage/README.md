# `useLocalStorage` exercise

## Цель

Отработать lazy initialization, синхронизацию React state с внешней системой, обработку ошибок и generics в TypeScript.

## Требования

Создайте `useLocalStorage.ts` с хуком:

```ts
useLocalStorage<T>(key, initialValue)
```

Хук должен:

1. При первом рендере прочитать значение из `localStorage`.
2. Использовать `initialValue`, если ключ отсутствует.
3. Не падать при ошибочном JSON: использовать `initialValue` и оставить понятное диагностическое сообщение.
4. После изменения React state сериализовать новое значение в `localStorage`.
5. Поддерживать строки, числа, boolean, массивы и объекты через generic `T`.
6. Не использовать `any` и type assertions `as`.
7. Не читать `localStorage` заново на каждом рендере.

## Перед кодом

Запишите ответы в комментарии в начале `useLocalStorage.ts`:

1. Что является источником начального значения?
2. Почему функция, переданная в `useState`, называется lazy initializer?
3. Какая операция синхронизирует React state с внешней системой?
4. От каких значений должен зависеть эффект записи?
5. Что произойдёт, если `key` изменится после первого рендера?
6. Чем ошибка чтения отличается от отсутствующего значения?

## Самостоятельная попытка

Сначала создайте сигнатуру и запишите псевдокод чтения и записи. Затем реализуйте рабочий вариант. Не добавляйте компонент-демонстрацию до review самого хука.

## Проверка

```bash
npm run build:sandbox
npm run lint
```

После автоматических проверок вручную проверьте перезагрузку страницы, отсутствующий ключ и заранее записанную некорректную JSON-строку.
