# Timer exercise

## Цель

Отработать `useState`, `useEffect`, функциональное обновление состояния и очистку ресурсов.

## Требования

1. Таймер показывает количество прошедших секунд.
2. `Start` запускает увеличение значения раз в секунду.
3. `Pause` останавливает таймер, сохраняя текущее значение.
4. `Reset` останавливает таймер и возвращает значение к нулю.
5. Повторное нажатие `Start` не создаёт дополнительные интервалы.
6. Интервал очищается при остановке таймера и размонтировании компонента.
7. Не использовать `any` и type assertions `as`.

## Перед кодом

Ответьте комментариями в `Timer.tsx`:

1. Какие значения должны храниться в состоянии и каковы их типы?
2. Какое событие запускает эффект?
3. При каких условиях эффект создаёт интервал?
4. Когда должна вызываться функция очистки?
5. Почему счётчик внутри интервала лучше обновлять через предыдущее значение?
