# Kanban

Учебное упражнение: три колонки, добавление задач, перенос между колонками и удаление через корзину. [Исходное условие](https://teal-produce-2f9.notion.site/25e1f21638f581ddb289e5e207942c44).

Массив Task[] хранится в KanbanBoard. Колонки получают массивы по status, форма передаёт обрезанный title через callback. TaskCard регистрирует draggable по id задачи; TaskColumn и TrashZone регистрируют droppable по статусу и id trash.

Обработчик onDragEnd сначала проверяет отмену и наличие source/target. Ветка trash удаляет задачу через filter до проверки допустимых статусов. Перенос меняет только выбранную задачу через map и новый объект. Остальные задачи сохраняются.

Реализация выполнена учеником с пошаговыми подсказками. [Журнал, проверки и темы повторения](../../../../docs/learning/2026-10-02-day-05-pet-project.md).

Проверено: пустой ввод, trim и очистка поля, перенос между колонками и в пустую колонку, Escape, отпускание вне области и в той же колонке, удаление одной задачи без потери остальных. Сборка и lint проходят. Сортировка внутри колонки и сохранение после перезагрузки не предусмотрены условием.
