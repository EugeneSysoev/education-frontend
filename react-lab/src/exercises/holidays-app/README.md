# Holidays App exercise

## Источник задачи

[React Practice Calendar — «Приложение для праздников»](https://teal-produce-2f9.notion.site/25e1f21638f58191a2c0e104fcaf48cd)

Создайте React-приложение, которое показывает государственные праздники текущего года для выбранной страны.

## API

Официальная документация: [OpenHolidays API](https://www.openholidaysapi.org/en/api/).

Нужны два GET-запроса:

```text
https://openholidaysapi.org/Countries?languageIsoCode=en

https://openholidaysapi.org/PublicHolidays
  ?countryIsoCode=NL
  &validFrom=2026-01-01
  &validTo=2026-12-31
  &languageIsoCode=en
```

Год вычисляйте во время выполнения, а не храните строкой `2026` в логике приложения.

## Функциональные требования

1. На экране есть выпадающий список поддерживаемых стран.
2. По умолчанию выбраны Нидерланды (`NL`).
3. Для выбранной страны показываются государственные праздники текущего года.
4. Для каждого праздника отображаются дата и английское название.
5. Отдельно представлены loading, error, empty и success состояния.
6. При смене страны список обновляется без перезагрузки страницы.

## Учебные ограничения

- Получайте server state через `@tanstack/react-query`.
- Храните выбранную страну в локальном React state.
- Вынесите `fetch` из React-компонента в функции data layer.
- Проверяйте `response.ok` до чтения успешного результата.
- На границе API начинайте с `unknown` и проверяйте минимальную форму данных.
- Используйте минимальные типы только для реально отображаемых полей.
- Реализуйте без `any` и type assertions `as`.
- Стилизация начинается после рабочей функциональности; Paper CSS необязателен для первой версии.

## Перед кодом

Ответьте своими словами:

1. Какие данные здесь являются server state, а какие local state?
2. Почему список праздников зависит от выбранной страны и текущего года?
3. Какие значения должны входить в `queryKey` праздников?
4. Чем отклонённый `fetch` отличается от HTTP-ответа со статусом `404` или `500`?
5. Почему TypeScript не может гарантировать форму JSON, пришедшего по сети?
6. Какие минимальные поля нужны интерфейсу из ответа страны и праздника?
7. Каким должен быть стабильный `key` элемента праздника?
