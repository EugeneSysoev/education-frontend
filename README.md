# Frontend Learning Lab

Учебный репозиторий для интенсивной подготовки к работе Frontend-разработчиком.

## Рабочий цикл

1. Прочитать условие и сформулировать вопросы по неоднозначным требованиям.
2. Сделать самостоятельную попытку без готовых решений.
3. Запустить проверки и локализовать ошибки.
4. Отправить код на review.
5. Исправить замечания и объяснить принятые решения.
6. Заполнить запись текущего дня, обновить матрицу навыков, сделать осмысленный Git-коммит и push.

Текущий день, история и следующий шаг находятся в [`docs/learning/README.md`](docs/learning/README.md). Новая сессия Codex начинает работу с [`AGENTS.md`](AGENTS.md).

Интенсивный график с 2 октября, формат помощи, работа над пет-проектом и применение идей четырёх книг описаны в [`docs/learning/learning-system.md`](docs/learning/learning-system.md). Базовый рабочий шаблон 08:00–16:15 включает 7 часов активной работы и 75 минут отдыха; поздний старт 2 октября и изменённый фокус записаны в активном дне. Даты и фокусы ближайших занятий — в [плане 2–8 октября](docs/learning/2026-10-02-week-plan.md).

## Структура

- `javascript/` — диагностика и упражнения по JavaScript.
- `typescript/` — диагностика и упражнения по TypeScript.
- `react-lab/` — лаборатория React на TypeScript и Vite.
- `docs/learning/` — хронология, планы и результаты по учебным дням.
- `learning-log/` — матрица навыков и прежние журнальные записи.
- `market-prep/` — подготовка к техническим собеседованиям.

Завершённая практика 1–2 октября: [Hacker News](docs/learning/2026-10-01-hacker-news.md). [Kanban 2–3 октября](docs/learning/2026-10-02-day-05-pet-project.md) реализован с подсказками и проверен. [Следующий план](docs/learning/2026-10-05-day-06-typescript-and-movie-search.md): повторение Kanban, теория TS и поиск фильмов; большой пет-проект остаётся в очереди. Завершённый JS-блок остаётся доступен для короткого закрепления: [`javascript/practice/gap-closing-01`](javascript/practice/gap-closing-01/README.md).

## Команды первого дня

```bash
npm test
npm run test:watch
```

На первом дне внешние зависимости не используются: тесты запускаются встроенным модулем `node:test`.
